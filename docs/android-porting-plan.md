# Yovoice Android 移植计划

## 当前阶段：Android 原生基础宿主

当前 APK 原型提供：
- Android 原生启动界面。
- 调用设备已安装的系统 TextToSpeech 服务进行文字试听。
- 通过 Android 系统文件选择器导入本地音频并试听。
- 不需要自建服务器；当前功能在设备本地执行。

## 尚未移植的桌面能力

以下能力不能仅靠 WebView 或空白按钮视为完成，需分别完成 Android 推理与数据层适配：
- Kokoro、Qwen3-TTS 等语音合成与声音克隆模型。
- ASR 语音识别与字幕导出。
- 故事配音、角色音色与项目管理。
- 音乐生成、音轨分离、MIDI/乐谱及时间线编辑。
- 模型下载、校验、缓存、内存管理与后台任务。

## 移植原则

1. 原桌面工程保留，不覆盖现有业务代码。
2. Android 端优先验证轻量、可在设备本地运行的语音模型。
3. 模型按需下载，不将大型模型塞入 APK。
4. 逐项实现后增加真机测试；未验证的能力明确标记为未支持。
5. 8GB 内存设备优先控制模型常驻与并发，不承诺所有桌面模型均可运行。
